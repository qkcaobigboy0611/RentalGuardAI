##项目名称：智能租房反欺诈分析系统

#
####项目概述

智能租房反欺诈分析系统是一个基于人工智能和大语言模型的专业化风控解决方案，专门针对租房平台中的聊天欺诈行为进行智能检测和实时预警。该系统通过先进的向量检索技术和多模型架构，实现了高效准确的欺诈模式识别，为平台用户提供全方位安全保障。

#
####技术架构亮点

#####核心框架

（1）**SpringBoot**:微服务架构

（2）**多模型支持架构**：支持DeepSeek云服务和Ollama本地模型的双重方案
#
#####智能检索系统

（1）向量嵌入技术：集成阿里云百炼text-embedding-v4模型生成高质量本文向量

（2）相似度计算：基于余𫠊相似度的智能案例检索算法

#                    
#####AI服务架构
（1）DeepSeek云服务：高性能大语言模型API集成
（2）Ollama本地部署：支持本地化模型部署，确保数据隐私和成本控制
（3）服务降级策略：智能故障转移和服务可用性检测

#
#####高级特性
（1）智能提示词工程：动态Prompt构建，支持上下文感知的AI交互

#
####技术栈详情

####后端技术

（1）Java17+SpringBoot3.x

（2）Mybatis+Mysql

（3）RestTemplate+HTTP Client
         

####AI集成
（1）DeepSeek API

（2）阿里云百炼向量模型

（3）Ollama本地模型


####部署架构
（1）云原生部署支持

（2）本地化部署支持
